# Zombie Apocalypse Guns

Zombie Apocalypse Guns is a Minecraft Fabric mod that transforms the world into a zombie apocalypse survival experience with a variety of guns, ammo, custom zombie types, modifiable weapons, and survivor villagers. This mod adds five distinct firearms, five ammo types, four custom zombies with unique behaviors, and a friendly survivor NPC that trades supplies. Weapons can be modified with attachments like scopes, suppressors, extended magazines, and laser sights. The mod introduces herd-based gameplay with fast zombies, tank zombies, spitter zombies that poison you from range, and brute zombies that apply weakness effects.

## Install

1. Download the `zombie-apocalypse-1.0.0.jar` file from the release page.
2. Install Fabric Loader 0.15.11 or newer for Minecraft 1.20.1.
3. Install Fabric API 0.92.0+1.20.1.
4. Place the `zombie-apocalypse-1.0.0.jar` file into your Minecraft `mods` folder.
5. Launch Minecraft with the Fabric profile.

## Use

1. After launching, find the Zombie Apocalypse creative tab to access all guns, ammo, attachments, and bandages.
2. Equip a gun and right-click to fire (sneak + right-click to open the gun modification screen).
3. Reload by having the matching ammo in your inventory — pressing fire with an empty gun automatically reloads.
4. Apply attachments like scopes or suppressors via the gun modification screen to change gun behavior.
5. Find Survivor villagers in the world, right-click them to trade for guns, ammo, and supplies.
6. Fight custom zombie types: Fast Zombies are quick, Tank Zombies are heavily armored, Spitter Zombies poison from range, and Brute Zombies weaken you on hit.
7. Use Herbal Bandages to heal yourself when injured.
